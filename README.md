# Gym Buddy AR Fitness Trainer Assistant

A Vite + React web app with a black and white Gym Buddy UI and animated 3D exercise guide using Three.js.

## Install

```bash
npm install
npm run dev
```

## Put your GLB files here

```txt
public/models/
```

Required filenames:

```txt
push_up.glb
air_squat.glb
jumping_jack_sample_animation.glb
burpee.glb
bodyweight_crunch_3d_animation.glb
barbell_bicep_curl_3d_animation.glb
overhead_crescent_lunge.glb
```

If your model filename is different, either rename the file or edit the `model` path in `src/App.jsx`.
